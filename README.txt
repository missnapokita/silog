BISAYA TOOLKIT VIP VOUCHER - GITHUB PAGES

STAGE 1: UPLOAD AND GET THE PAGE LINK

1. Create a new public GitHub repository. Suggested name: bisaya-voucher
2. Upload everything inside this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then press Save.
6. Wait for GitHub Pages to publish the website.

Your normal page will look like:
https://YOUR-USERNAME.github.io/bisaya-voucher/

IMPORTANT SHORTENER DESTINATION

Use the /claim/ address as the destination of your shortened link:
https://YOUR-USERNAME.github.io/bisaya-voucher/claim/

After generating the shortened link, send both of these:
- Normal GitHub Pages link
- Shortened link

Do not put any API key, admin key, password, or secret in config.js.
The page is intentionally in SETUP MODE until the shortened link and secure voucher API are connected.
